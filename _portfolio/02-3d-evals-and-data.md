*404-GEN · 2025–present*

Agent-orchestrated A/B testing, LLM/VLM-as-a-judge and CI/CD regression checks that decide what ships, plus the data flywheel that feeds training.

## What I did

- Built agent orchestration workflows for CI/CD regression testing, LLM-as-a-judge evaluation, and automated human A/B testing that generate benchmarks.
- Agentic framework for **automated human A/B testing**, benchmarking, and validating **80–90% quality gains over baseline models** in production.
- Validated the LLM/VLM-as-a-judge against internal gold-standard labeled data and stress-tested it with brute-force methods to detect failure modes.
- Architected an automated evaluation harness with score-based render-quality estimation and prompt-alignment pipelines (VQAScore vs. CLIP).
- Engineered automated ingestion and filtering pipelines to curate multimodal 3D assets with human-aligned quality scores for pre-training and post-training.
- Instituted CI/CD regression testing via agent orchestration to catch prompt drift, visual artifacts, and mode collapse before release.
